# Code of conduct

We want Monetary to be a welcoming project for everyone who contributes, reports issues or asks questions.

## Expected behavior

- Be respectful and constructive. Criticize code and ideas, not people.
- Assume good faith, and welcome newcomers and different levels of experience.
- Give and accept feedback graciously; stay on topic in issues and pull requests.

## Unacceptable behavior

- Harassment, insults, discrimination, threats or personal attacks of any kind.
- Publishing someone else's private information.
- Sustained disruption of discussions, or other conduct that would reasonably be considered inappropriate
  in a professional setting.

## Enforcement

The maintainer may edit or remove comments, issues and pull requests, and may temporarily or permanently
block people who break these rules. To report a problem, use GitHub's private
[vulnerability reporting](SECURITY.md) channel or contact the maintainer through their GitHub profile.

This code applies in all project spaces (issues, pull requests, discussions) and when someone represents the
project in public.
